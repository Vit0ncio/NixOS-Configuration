# ❄️ NixOS-Configuration
Repositório para armazenar minhas configurações do NixOS.  

Conforme o tempo irei adicionando mais coisas e configurações.

## Instalação
1. Baixe o arquivo `configuration.nix` para uma máquina com Nix instalado
2. Adicione esse arquivo em: `etc/nixos/`, se pedir pra substituir, substitua
3. Vá para o terminal e digite `sudo nixos-rebuild switch`
